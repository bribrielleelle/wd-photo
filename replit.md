# Project setup

This is a React + TypeScript photo gallery built with Vite and Tailwind CSS.

## Run on Replit

- Start the app with the **Start application** workflow.
- The workflow runs `npm run dev`.
- Vite serves the app on `0.0.0.0:5000` for Replit Preview.

## Checks

- Type-check: `npm run lint`
- Production build: `npm run build`
